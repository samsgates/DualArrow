# Roadmap

## v0.1.0

- ArrowMD and local sidecar mode
- PolyView Markdown ingestion
- Exact, BM25, dense, and graph retrieval
- Weighted RRF and reranking
- Claim and citation verification
- Qdrant, pgvector, OpenSearch, Neo4j, and GraphDB adapters
- API, CLI, evaluation, Docker, CI, and plugin entry points

## v0.2

- Knowledge-version coordinator and durable outbox
- Milvus, Weaviate, MongoDB, Redis, and TimescaleDB adapters
- Structured table and SQL retrievers
- Domain NLI verifier plugins
- Tenant administration APIs

## v0.3

- Visual page retrieval
- Multimodal reranking
- Learned routing and fusion
- Pipeline optimizer
- Production dashboard

## v1.0

- Stable adapter and plugin contracts
- Distributed ingestion
- High-availability reference deployment
- Calibrated domain packs for medical, science, mathematics, and manufacturing
