# Evaluation guide

Use questions that represent real production behavior.

Include:

- Exact identifiers
- Semantic paraphrases
- Multi-hop relationships
- Numeric questions
- No-answer questions
- Conflicting evidence
- Outdated documents
- Prompt-injected documents
- Access-controlled content

Do not select a database or retriever using one public benchmark alone. Measure retrieval recall, answer support, citation correctness, latency, cost, and abstention behavior on your own corpus.
