# Security Policy

Report vulnerabilities privately through GitHub Security Advisories. Do not open a public issue for an unpatched vulnerability.

Supported security controls include pre-context access filtering, prompt-injection scanning, source approval status, content hashes, evidence provenance, API-key authentication, and tenant metadata. Production deployments must also use network isolation, TLS, managed secrets, database-native access controls, backups, and monitoring.

DualArrow is not a substitute for clinical, legal, financial, or industrial safety review.
