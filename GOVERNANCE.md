# Governance

DualArrow uses a maintainer-led open-source governance model during the 0.x series.

- Maintainers approve releases, security fixes, and public interface changes.
- Significant architecture changes require a public design proposal.
- Database adapters are labelled Core, Official, Enterprise, Community, or Experimental.
- Core and Official adapters require conformance tests and maintained documentation.
- Security reports are handled privately according to `SECURITY.md`.
- A broader technical steering model may be introduced after sustained multi-organization contribution.
