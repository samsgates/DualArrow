# BR-442 Bearing Specification

## Compatibility

BR-442 is compatible with the P-104 and P-104X press machines. BR-442 must not be installed in P-103 machines.

## Installation

Apply 42 newton-metres of torque to each bearing housing bolt using a calibrated torque wrench. Use lubricant L-17 and do not mix it with lithium-complex lubricant.

## Failure indicators

Rapid temperature increase after installation can indicate excessive preload, incorrect lubricant, housing misalignment, or insufficient run-in time.
